## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento do meu **portfólio profissional**, criado para centralizar minha apresentação profissional e reunir projetos desenvolvidos ao longo da minha jornada na programação.

O objetivo é apresentar, de forma simples e moderna, minhas **habilidades técnicas, projetos, experiências e formas de contato**, além de demonstrar na prática meus conhecimentos no ecossistema front-end moderno.

---

## 🚀 Tecnologias utilizadas

A aplicação foi construída utilizando as seguintes tecnologias e ferramentas:

- ⚛️ **React** — Biblioteca principal para construção da interface baseada em componentes
- ⚡ **Vite** — Build tool rápida e otimizada para o desenvolvimento
- 🎨 **Tailwind CSS** — Framework CSS utilitário para estilização rápida e responsividade
- 🎬 **Framer Motion** — Biblioteca utilizada para criar animações fluidas
- 🟨 **JavaScript (ES6+)** — Lógica principal de componentes
- 🌐 **HTML5 & CSS3** — Estrutura e estilos tradicionais base do projeto

---

## ✨ Características

- 📱 Interface 100% responsiva (Mobile First)
- 🎨 Design moderno e arquitetura baseada em componentes
- 🎬 Animações de entrada e transições de tela suaves
- 💻 Apresentação dos meus principais projetos
- 👨‍💻 Seção detalhada sobre meus conhecimentos e stack técnica
- 📬 Informações diretas para contato
- 🌐 Deploy contínuo configurado via Vercel
