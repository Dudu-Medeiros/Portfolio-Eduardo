## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento do meu **portfólio profissional**, criado para centralizar minha apresentação profissional e reunir projetos desenvolvidos ao longo da minha jornada na programação.

O objetivo é apresentar, de forma simples e moderna, minhas **habilidades técnicas, projetos, experiências e formas de contato**, além de demonstrar na prática meus conhecimentos em desenvolvimento web.

---

## 🚀 Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais para desenvolvimento Front-end:

* 🌐 **HTML5** — Estruturação semântica das páginas
* 🎨 **CSS3** — Estilização, responsividade e criação da interface
* ⚡ **JavaScript** — Interatividade e funcionalidades da aplicação

## 🛠️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Dudu-Medeiros/Portfolio-Eduardo.git
```

### 2. Acesse a pasta do projeto

```bash
cd Portfolio-Eduardo
```

### 3. Abra o projeto

Você pode abrir o arquivo `index.html` diretamente no navegador ou utilizar uma extensão como **Live Server** no Visual Studio Code.
